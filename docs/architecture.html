One binary · one sqlite file · HTMX pages

Goholic is a house with named rooms.

A reader never talks to sqlite. A writer never talks to HTML templates from the librarian. Each package has one job. That is the whole architecture. Module github.com/anti-gravity-bit/goholic, entry cmd/goholic-web-server.

Startup: read env → open sqlite cabinet → hire librarian → plant seed stories if empty → mint writer passport → bind routes on the default mux → ListenAndServe. No Node build. Templates and CSS are Go string constants.

PRAGMA foreign_keys=ON (unused — no child tables). journal_mode=WAL. No busy_timeout. No migrations folder: schema is CREATE TABLE IF NOT EXISTS in OpenSqliteArticleShelfFile.

Markdown (intentional subset)

Implemented in webpage.TurnMarkdownIntoSafeHtml:

  • # ## ### headings
  • - unordered lists
  • **bold** and `code`
  • Blank lines → paragraphs
  • Raw HTML escaped first, then marks applied

Not implemented: links, images, italics, fenced blocks, blockquotes, numbered lists. That is a product gap, not a bug — unless you want a real blog body.

Auth cookie

Name goholic_writer_session. Value {unix}.{hmac-sha256-hex}. Lifetime 12h (server-side). HttpOnly, SameSite=Lax, Secure if TLS or X-Forwarded-Proto: https. Password bcrypt’d at process start from env. HMAC is not bound to the username. Login cookie has no MaxAge (browser session).

Build next

Slice 1 — Stop shipping with toy secrets

Refuse to boot if password/secret are the compiled defaults. Read GOHOLIC_SITE_BASE_URL or delete it from .env.example. File: cmd/goholic-web-server/main.go.

Slice 2 — A real http.Server

Timeouts (ReadHeader, Read, Write, Idle), graceful shutdown on SIGINT, own ServeMux instead of the default. Enables tests that do not share global mux state. File: main.go + small change to BindRoutes… to take a mux.

Slice 3 — Writer desk hardening

CSRF token on POST/DELETE, login constant-time username compare, cookie MaxAge=12h, bind HMAC to username. Files: writerpassport, webpage_server.go, login/dashboard templates.

Slice 4 — Honest sqlite errors + busy_timeout

Inspect sqlite3.ErrConstraintUnique (or string) before returning ErrArticleSlugAlreadyTaken. Set PRAGMA busy_timeout=5000. File: sqlite_article_shelf.go.

Slice 5 — Blog that looks finished

Markdown links + fenced code. RSS at /feed.xml. Open Graph / canonical using the unused base URL. Custom 404. Optional: hide “Writer desk” from the public nav or keep it as a flex. Files: simple_markdown.go, html_layout.go, new feed handler.

Slice 6 — Public repo hygiene

MIT, CI go test ./..., do not commit the 16MB binary or sqlite (gitignore already says so — delete the working copies from the tree before git init). Vendor HTMX or pin + SRI. Empty web/ folder: use it for templates or remove it.

Slice 7 — Deploy Path A

Follow docs/CLOUDFLARE_ROADMAP.md: image, volume, tunnel, cache bypass /writer, Access on the desk, nightly sqlite copy. Distroless + VOLUME /app/data needs the volume writable by nonroot.

Slice 8 — Only if the blog outgrows a file

postgresarticleshelf keeping the same interface. Thread context.Context through the shelf first — that is the real architecture follow-up, not a second database for its own sake.
